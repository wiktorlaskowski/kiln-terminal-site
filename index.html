A modern GTK4 terminal that feels at home on GNOME.

Kiln Terminal is a native C++ terminal emulator built on GTK4, libadwaita, and VTE. It detects every shell on your system, opens them in tabs or split panes, and follows your system's dark‑mode preference out of the box.

Install Build from source

Built and tested on Ubuntu 24.04 / Linux Mint 22 (noble).

What it does

Multi-shell new-tab button

A split button in the header bar opens a menu of every shell found in /etc/shells and the usual locations (bash, zsh, fish, dash, tmux, nushell, …). Pick one per tab.

Horizontal & vertical splits

Slice a tab into panes with Ctrl+Shift+D or Ctrl+Shift+E. Close a pane and the remaining one reclaims the space automatically.

Right-click menu

Copy, paste, select all, split, open a new tab, or close the pane — all from a native GtkPopoverMenu anchored to the click location.

Follows the system theme

Uses AdwStyleManager to track GNOME's light/dark preference live. Palette and background are swapped at runtime — no restart, no theme file to tweak.

Spawns proper login shells

Each tab is spawned with G_SPAWN_FILE_AND_ARGV_ZERO so argv[0] is -bash, -zsh, etc. Your rc files run exactly the way they do from a TTY.

Inherits the current working directory

New tabs and split panes open in the focused shell's foreground process's cwd, so cd-ing somewhere and hitting new-tab keeps you there.

Defensive shell validation

Shell paths are validated before spawn: absolute path only, no control characters, and the target must match something the detector found. A shell uninstalled between menu build and click falls back to the user's default.

Debian package & APT index

Ships as a hardened .deb built with debhelper 13 and hardening=+all. A Packages.gz is generated so you can host it as a flat APT repo.

Install

Grab the .deb and install it, or add the APT repo where it's hosted to get updates.

Direct .deb

sudo apt install ./kiln-terminal_1.2.0-1_amd64.deb

Uses your system's package manager to resolve GTK4, libadwaita-1, and VTE runtime deps.

Via the APT repo

echo "deb [trusted=yes] https://wiktorlaskowski.github.io/kiln-terminal/ ./" \
  | sudo tee /etc/apt/sources.list.d/kiln.list
sudo apt update
sudo apt install kiln-terminal

Hosted on GitHub Pages as a flat APT repo (Packages.gz at the root).

Uninstall

sudo apt remove kiln-terminal

Or run ./install.sh --uninstall if you installed from source.

Build from source

Kiln Terminal builds with plain CMake and pkg-config. No vendored dependencies, no extra toolchain.

Dependencies

  • cmake ≥ 3.20
  • pkg-config
  • libgtk-4-dev
  • libadwaita-1-dev
  • libvte-2.91-gtk4-dev
  • A C++20 compiler

Commands

git clone -b Source https://github.com/wiktorlaskowski/kiln-terminal.git
cd kiln-terminal
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j$(nproc)
./build/kiln-terminal

To build a .deb instead, run ./build-deb.sh.
